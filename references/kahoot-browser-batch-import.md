# Kahoot 瀏覽器批次匯入流程

只有在使用者明確要求將既有 `.xlsx` 題庫直接匯入 Kahoot 時才讀取並使用本文件。單純產生、驗證或下載題庫時，不啟動瀏覽器操作。

## 任務結果

使用使用者已授權且已登入的 Kahoot 瀏覽器工作階段，依「年級、教學單元、活動名稱」逐一建立新測驗、匯入題庫、命名並儲存，最後交付完整或可續作的 Kahoot 連結清單。

## 接受的輸入

- 包含多個 `.xlsx` 題庫的資料夾。
- 一個包含 `.xlsx` 題庫的 ZIP 壓縮檔。
- 多個個別 `.xlsx` 檔案。
- 使用者已登入 Kahoot 的瀏覽器分頁或視窗。

檔名通常使用：

```text
三年級_水的變化_水的三態.xlsx
四年級_天氣變化_雲和霧.xlsx
五年級_植物世界_植物的繁殖.xlsx
六年級_天氣變化_颱風與防災.xlsx
```

可接受前置序號或 `_Kahoot` 後綴。能可靠解析時，以「年級｜教學單元｜活動名稱」作為測驗標題；無法解析時保留原始檔名主體，並在清單中標示待確認，不自行猜測。

## 安全與授權界線

1. 只能操作使用者已授權的 Kahoot 帳號與其指定題庫。
2. 明確的批次匯入請求只授權建立這一批新測驗，不授權編輯、覆蓋、刪除、分享或公開既有內容。
3. 不得要求使用者在對話中提供密碼。若尚未登入，暫停並請使用者在瀏覽器中自行登入。
4. 遇到雙重驗證、驗證碼、CAPTCHA、帳號選擇或安全確認時，暫停並等待使用者完成，不得繞過安全機制。
5. 優先使用 Kahoot 官方 Creator 介面。不得假設存在公開 API；只有使用者提供正式 API 文件與合法授權時才可改走 API。
6. 依畫面中可見的文字、標籤、角色與目前狀態定位操作，不依賴固定座標或未驗證的舊版步驟。
7. 保留 Kahoot 當下的預設隱私設定；除非使用者明確要求，不變更可見性、分享或發布狀態。
8. 只移除已確認為空白且由建立流程自動產生的預設題，不刪除已匯入或既有題目。
9. 每完成一個檔案，都要取得可觀察的儲存成功證據並記錄連結，才能進入下一個檔案。
10. 若無法判斷是否已建立或儲存成功，不得直接重做，以免產生重複測驗；先檢查內容庫或目前頁面，仍不確定就停止。

## 操作前檢查

1. 若輸入為 ZIP，解壓到新的任務專用資料夾，不修改或刪除原始檔。
2. 列出所有預計處理的 `.xlsx`，排除暫存檔、隱藏檔及非題庫檔案。除非使用者另有指定，依相對路徑與檔名排序。
3. 在本機檢查每個檔案可開啟、含題目、必要欄位存在，且正確答案編號、時間值與空白選項符合當次 Kahoot 官方範本。任何檔案不合格時，先修正或列為阻擋，不把明知無效的檔案送入瀏覽器。
4. 建立批次工作清單，至少包含：順序、來源檔、年級、教學單元、活動名稱、預定標題、狀態、Kahoot 連結與備註。
5. 確認可控制的是使用者指定且已登入的 Kahoot 分頁。若環境提供專用瀏覽器自動化技能或工具，先遵循其操作與確認規則。

## 逐檔匯入

對每個尚未完成的檔案依序執行：

1. 從 Kahoot 官方 Creator 介面建立新的 Kahoot，不從既有測驗覆製或覆蓋內容。
2. 若編輯器自動建立一題空白題，先確認它確實沒有使用者內容，再移除。
3. 從目前畫面尋找「匯入試算表」或語意相同的可見入口，選取當前清單中的單一 `.xlsx`。
4. 等待匯入處理完成，檢查成功訊息、錯誤訊息、匯入題數與可見題目。若題數為零、部分題目遭拒或格式錯誤，不得把該檔標記為完成。
5. 依工作清單填入測驗標題。不要修改題目內容、封面、描述、可見性或其他欄位，除非完成匯入確實需要，或使用者已另外指定。
6. 執行儲存或完成動作。只有看到成功提示、已儲存狀態、內容庫項目或其他足以證明保存成功的可觀察結果，才記錄為成功。
7. 從已儲存測驗的詳情頁、內容庫項目或可穩定重新開啟的位置取得 Kahoot 連結，不把尚未儲存的 Creator 暫存網址當成交付連結。
8. 立即更新工作清單，再處理下一個檔案。

## 暫停、錯誤與續作

- 登入、雙重驗證、CAPTCHA 或安全確認：狀態標記為「等待使用者」，保留目前頁面並暫停。
- 可明確修正的單一檔案格式問題：記錄題目或欄位錯誤，回到本機修正後再重試；未修正前不進入下一檔。
- 網路或頁面暫時失敗：只有在確認不會重複建立、目前狀態可辨識時才重試一次。
- 儲存結果不明、可能已建立重複測驗、介面流程與可見文字無法對應，或其他無法安全恢復的錯誤：立即停止整批作業並回報，不猜測、不覆蓋資料。
- 續作時以工作清單為檢查點。已成功且已有連結的項目不得重新建立；先從 Kahoot 內容庫確認狀態，再從第一個未完成項目繼續。

## 交付格式

交付 `Kahoot_匯入結果.md`；使用者需要時再附 CSV。即使中途暫停或失敗，也要輸出目前結果：

| 順序 | 來源檔案 | Kahoot 名稱 | 狀態 | 連結 | 備註 |
|---:|---|---|---|---|---|
| 1 | `三年級_水的變化_水的三態.xlsx` | 三年級｜水的變化｜水的三態 | 已完成 | https://... | 已確認儲存 |
| 2 | `四年級_天氣變化_雲和霧.xlsx` | 四年級｜天氣變化｜雲和霧 | 等待使用者 |  | 需要安全確認 |

只有同時確認成功儲存並取得穩定連結的項目才能標記為「已完成」。最後彙總總檔案數、成功數、等待使用者數、失敗數、未處理數與下一個續作項目。
