# 自然科 Kahoot 多元評量設計師

協助臺灣國小自然科教師從文字、截圖或教學網站建立題庫，完成評量品質檢核與科學查證，並在明確授權下將既有 `.xlsx` 題庫批次匯入 Kahoot。

目前版本：**v1.3.0**

## v1.3.0 新增功能

- 新增「Kahoot 瀏覽器批次匯入模式」。
- 接受題庫資料夾、ZIP 壓縮檔或多個 `.xlsx`。
- 依年級、教學單元與活動名稱逐一建立、命名及儲存 Kahoot。
- 每個檔案確認成功儲存後才處理下一個，降低漏存及重複建立風險。
- 產生包含來源檔案、Kahoot 名稱、處理狀態與連結的 `Kahoot_匯入結果.md`。
- 加入帳號授權、登入、雙重驗證、CAPTCHA、安全確認及錯誤停止規則。

## 四種工作模式

| 模式 | 適用情境 | 主要成果 |
|---|---|---|
| 快速互動選題 | 已知教學單元或活動，希望快速建立互動題目 | 候選題目卡、正式題庫、Kahoot `.xlsx` |
| 截圖／網站批次題庫 | 從課本目錄、課程架構截圖或教學網站擷取多個單元 | 分類題庫、批次索引、驗證摘要、ZIP |
| 完整評量 | 前測、形成性評量、後測、複習、雙向細目表或結果分析 | 命題藍圖、題目、解析、查證及學習分析 |
| 瀏覽器批次匯入 | 已有多份 `.xlsx`，需要建立 Kahoot 並取得連結 | 已儲存的 Kahoot 與完整連結清單 |

## 快速開始

明確呼叫技能：

```text
$natural-science-kahoot-assessment
```

### 快速建立題庫

```text
快速建立 Kahoot：六年級〈探索天氣變化〉；活動包括氣溫、雲量、風向與降雨觀測。
```

技能會整理核心概念、活動證據與常見迷思，讓教師複選互動內容、題型與候選題目，再完成評量驗證、科學查證及 `.xlsx` 輸出。

### 從截圖或網站批次建立題庫

```text
請從這些課本目錄截圖擷取教學單元與活動名稱，讓我複選後，每個活動各產生一份 Kahoot 題庫。
```

```text
截圖或網站 → 擷取單元／活動 → 複選項目
→ 統一設定題型 → 批次驗證 → 分類輸出題庫
```

### 建立完整評量

```text
請設計五年級「水溶液」單元的形成性評量，包含命題藍圖、教師解析、迷思診斷與 Kahoot 題庫。
```

### 批次匯入 Kahoot

```text
請將這個資料夾內的 Kahoot .xlsx 題庫依序匯入我已登入的 Kahoot，確認每份都儲存成功，最後整理連結清單。
```

## 支援的題型與輸出

### 題型

- 是非題、單選題與多選題
- 概念辨識與迷思概念診斷題
- 圖表／資料判讀題
- 實驗步驟、觀察結果與推論題
- 生活情境應用、科學推理與探究設計題

### 輸出

- Kahoot 官方 `.xlsx` 試算表題庫
- 題目總表、答案表與教師解析
- 迷思概念與補救教學建議
- 評量驗證及科學查證摘要
- PDF、Word、HTML、Markdown 或 CSV
- 批次索引、批次驗證摘要與 ZIP
- Kahoot 瀏覽器匯入結果及連結清單

實際可輸出的檔案取決於執行環境中可用的試算表、文件、PDF、簡報與瀏覽器工具。

## Kahoot 瀏覽器批次匯入

### 接受的輸入

- 包含多個 `.xlsx` 題庫的資料夾
- 含 `.xlsx` 題庫的 ZIP 壓縮檔
- 多個個別 `.xlsx` 檔案
- 使用者已登入 Kahoot 的瀏覽器分頁或視窗

題庫可依下列方式命名：

```text
三年級_水的變化_水的三態.xlsx
四年級_天氣變化_雲和霧.xlsx
五年級_植物世界_植物的繁殖.xlsx
六年級_天氣變化_颱風與防災.xlsx
```

能可靠解析時，Kahoot 名稱採用：

```text
年級｜教學單元｜活動名稱
```

### 匯入流程

```text
盤點並驗證題庫
    ↓
建立新的 Kahoot
    ↓
確認並移除預設空白題
    ↓
匯入單一 .xlsx
    ↓
命名並確認儲存
    ↓
擷取穩定連結並更新清單
    ↓
處理下一個檔案
```

每個檔案只有在確認成功儲存並取得穩定連結後，才能標記為「已完成」。如果中途暫停或失敗，仍會交付目前清單，以便從第一個未完成項目繼續。

```markdown
| 順序 | 來源檔案 | Kahoot 名稱 | 狀態 | 連結 | 備註 |
|---:|---|---|---|---|---|
| 1 | 三年級_水的變化_水的三態.xlsx | 三年級｜水的變化｜水的三態 | 已完成 | https://... | 已確認儲存 |
```

## 帳號與操作安全

- 只能操作使用者已授權的 Kahoot 帳號與指定題庫。
- 不會要求使用者在對話中提供密碼。
- 尚未登入時會暫停，由使用者在瀏覽器中自行登入。
- 遇到雙重驗證、驗證碼、CAPTCHA、帳號選擇或安全確認時會等待使用者完成。
- 不會繞過 Kahoot 的安全機制，也不會假設存在公開 API。
- 優先使用 Kahoot 官方 Creator 介面，依畫面可見文字及目前狀態操作，不依賴固定座標。
- 批次匯入只授權建立本批新測驗，不會因此編輯、覆蓋、刪除、分享或公開既有內容。
- 無法判斷測驗是否已建立或儲存時，不會直接重做，以免產生重複內容。
- 發生無法安全恢復的錯誤時會停止整批作業，保留進度並回報。

完整流程請參閱 [`references/kahoot-browser-batch-import.md`](references/kahoot-browser-batch-import.md)。

## 評量品質原則

- 每題必須有明確且可辯護的答案；多選題會列出所有正確選項。
- 題目優先評量解釋、應用、資料判讀與科學推理，不只測量記憶。
- 誘答來自合理的錯誤概念，避免以文字長度、語氣或排列位置暗示答案。
- 圖表與實驗題只使用題目已提供或可靠來源支持的資訊，不虛構數據。
- 題目完成後先進行評量品質檢核，再逐題查核科學內容。
- A 級問題未修正前，不會把題庫標記為完成。
- 未取得學生作答資料時，只標示「預期鑑別重點」，不宣稱已有實際鑑別度。

## Kahoot 格式提醒

- `.xlsx` 是 Kahoot 試算表題庫匯入格式。
- 產生可匯入檔案不等於已經寫入 Kahoot 帳號。
- 只有使用者明確要求、已授權瀏覽器操作且自行完成登入後，才會建立線上測驗。
- Kahoot 的欄位、字數、時間限制與支援題型可能更新，產檔前應查閱當次官方說明。
- PDF、PowerPoint、Google Slides 與網頁 URL 可作為 Kahoot AI 素材，但不等同於 `.xlsx` 直接匯入。
